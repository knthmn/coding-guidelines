# UI Styling

Applies when: Any project with a user interface that it styles itself.

Read a rule file only when the rule may apply. The file of rule `<rule-id>` is `rules/<rule-id>.md`.

- `animate-from-trigger-origin` [low] Set `transform-origin` on scaling popovers, menus and tooltips to the side facing the trigger, not the center. When: A popover, menu, tooltip or dropdown scales or zooms as it opens or closes.
- `balance-and-pretty-text-wrap` [low] Set `text-wrap: balance` on headings and `text-wrap: pretty` on short descriptions. Do not use either on long-form text. When: Headings, short descriptions or captions that can wrap to several lines.
- `button-press-scale` [low] Give pressable buttons an `:active` scale between 0.95 and 0.98, with a short ease-out transition on the `scale` property. When: A project styles buttons or other pressable controls with custom interaction states.
- `concentric-border-radius` [low] For a rounded element inside a rounded parent with padding, set the outer radius to the inner radius plus the padding. When: A rounded element sits inside another rounded element, with padding between them.
- `contain-long-text-and-labels` [medium] Use `overflow-wrap: break-word` on text that can hold long words, links or IDs. Use `white-space: nowrap` on labels and badges. When: User or system text with long unbroken strings, such as URLs, IDs and keys, or short labels and badges that must not wrap.
- `contrast-against-direct-background` [medium] Measure text and icon contrast against the background directly behind them, such as a card or a panel, not against the page background. When: Text or icons sit on a surface that differs from the page background, such as a card, a tinted panel or a banner.
- `crossfade-swapped-icons` [low] When one icon replaces another in the same spot, animate both: the new one scales from 0.25 and fades in with a blur, and the old one reverses. When: An icon changes in place on a state change, such as copy to check, play to pause or menu to close.
- `disable-transitions-on-theme-switch` [low] Turn off all transitions for one frame when the theme changes, so colors change together and not one by one. When: The app lets users switch between light and dark theme at runtime and styles use color transitions.
- `font-smoothing-antialiased` [low] Set `-webkit-font-smoothing: antialiased` and `-moz-osx-font-smoothing: grayscale` once on the root layout. When: The project sets global base styles, and its users include macOS.
- `group-spacing-twice-item-spacing` [low] Leave at least twice as much space between groups as between items inside a group, for example 8px between items and 16px or more between groups. When: A layout has lists, forms or settings with several groups of related items.
- `icon-stroke-matches-text` [low] Choose an icon stroke width that looks as thick as the text beside it, and keep it the same across one row. When: A stroked icon sits next to text in a button, menu item, tab or label.
- `image-edge-outline` [low] Add a `1px` outline with offset `-1px` to images, black at 8% opacity in light mode and white at 8% in dark mode. When: Images, avatars or thumbnails whose edge can blend into a similar page background.
- `interpolate-gradients-in-color-space` [low] Set the interpolation color space in a gradient, such as `in oklab`, `in oklch` or `in srgb`, when the default midpoint looks muddy. When: A gradient mixes two saturated colors or a color with white, black or transparent.
- `keep-frequent-interactions-instant` [low] Skip the open animation on menus people open often, and use no or very short transitions for hover and other high-frequency feedback. When: Menus, context menus, list items, tabs or buttons that people trigger many times per session.
- `layered-shadow-for-depth` [low] Give cards, menus and popovers a layered `box-shadow` with a faint 1px ring, instead of a solid border. When: A card, menu, popover or other raised surface gets its edge from a solid border.
- `limit-line-length` [low] Cap the width of articles and other long text at about 60-75 characters per line, for example `max-width: 65ch`. When: Articles, documentation, descriptions or other multi-line prose that can span a wide container.
- `name-color-tokens-by-purpose` [low] Name color tokens by use, such as `--color-accent-solid`, not by hue or location. Keep accent for the brand color and avoid a bare `primary` that means two things. When: A project defines or adds color tokens, CSS variables or Tailwind theme colors.
- `no-animation-on-page-load` [low] Make sure initial content and persistent UI render in place on page load. Enter animations should run only for elements that appear after load. When: Elements use enter animations, transition from an initial state, or hydrate with a state change.
- `optical-alignment` [low] Nudge icons and shapes that look off-center when the math is centered, such as play triangles and arrows. When: An asymmetric icon or glyph sits in a button, badge or label, and geometric centering makes it look shifted.
- `purposeful-palette-steps` [low] Define each step of a color scale for one use, such as background, hover, border, solid fill or text. Do not add steps that nothing uses. When: The project defines a color scale or palette, for example `gray-100` to `gray-1200` or a Tailwind theme.
- `reveal-truncated-text` [medium] When you cut text short with an ellipsis, give people a way to read the full text, such as a tooltip, an expand control or a detail view. When: Text is cut with `text-overflow: ellipsis`, `truncate` or `line-clamp`.
- `scroll-margin-for-anchor-targets` [medium] Give headings and sections that links can target a `scroll-margin-top`, so a sticky header does not cover them. When: The page has a sticky or fixed header and headings or sections with ids that links or the URL hash point to.
- `separate-dark-mode-palette` [low] Define dark mode token values by hand for dark surfaces. Do not invert the light scale or apply a filter. When: The project supports a dark theme.
- `single-theme-switch-mechanism` [medium] Choose either the `prefers-color-scheme` media query or a `.dark` class (or data attribute) for theming. Do not mix both in the same styles. When: The project supports dark mode.
- `stagger-entrances-in-groups` [low] Animate entering content in small groups, such as heading, text and actions, with a short delay between groups. Do not animate one large block or each word. When: A section of a page or a panel animates in with several parts.
- `subtle-exit-animations` [low] Move an exiting element a shorter distance than it traveled in, and fade it out, optionally with a small blur. When: An element has both an enter and an exit animation, such as toasts, popovers, drawers or list items.
- `tabular-numbers-for-changing-values` [low] Set `font-variant-numeric: tabular-nums` on timers, counters, prices and table columns, so digits keep the same width. When: Numbers update in place or line up in columns, such as timers, counters, prices and tables.
- `text-transform-for-letter-case` [low] Write strings in normal capitalization and use CSS `text-transform` to show uppercase, lowercase or capitalized text. When: A label, heading or badge is shown in all caps, lowercase or title case.
- `transition-named-properties` [low] List the exact properties to animate in `transition-property`. Do not use `transition: all` or the Tailwind `transition-all` class. When: CSS or Tailwind code sets a transition.
- `transitions-for-interactions-keyframes-for-sequences` [low] Animate interactive state changes with CSS transitions so they can reverse midway. Use keyframes only for sequences that run once. When: An animation reacts to user input, such as open and close, hover, toggle or drag, or runs as a one-time sequence.
- `underline-skip-ink` [low] For underlined text, set `text-underline-position: from-font` and `text-decoration-skip-ink: auto`, so lines do not cut through g, y and p. When: The project underlines links or text with `text-decoration`.
- `use-semantic-color-tokens` [low] Components reference tokens named by purpose, such as `--color-text-secondary`, never primitives such as `--blue-500`. When: The project has CSS variables, a Tailwind theme or design tokens for color.
- `use-smart-punctuation` [low] Use curly quotes, an en dash for ranges, an em dash for asides and the ellipsis character in text that people read. When: A project writes user-facing strings, headings, labels or marketing copy.
- `use-woff2-web-fonts` [low] Load web fonts from `.woff2` files. Do not ship `.ttf` or `.otf` files to browsers. When: The project declares `@font-face` rules or loads self-hosted font files.
- `will-change-for-animation-jitter` [low] When an animated element shifts by 1-2px during or after a transform animation, add `will-change: transform` to that element only. When: A transformed element visibly jitters or snaps by 1-2px at the start or end of an animation, reported mainly in Safari on iOS.
